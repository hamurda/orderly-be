# Orderly — Backend API

Backend API built for a small business client. Clean architecture 
with four layers: API, Application, Domain, and Infrastructure.

## Stack
ASP.NET Core · PostgreSQL · ASP.NET Core Identity

## Architecture
- CQRS pattern with commands, queries, handlers, and validators
- Role-based authentication and authorization via ASP.NET Core Identity
- Layered architecture with clear separation of concerns
